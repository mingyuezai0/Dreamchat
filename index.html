梦语

梦语是一款连接各家大模型接口的多 AI 人物群聊软件，纯浏览器本地运行：和多位 AI 角色在「群聊」聊天，或写下「故事」让它们一起演剧情，记录保存在本机。

全局设置

默认官方 DeepSeek 地址，可改成任意 OpenAI 兼容服务的地址（各服务通常以 /v1 结尾）。

填你所选接口服务商发的 API Key（可在其官网注册获取）。

手填模型名，各家格式不同（如 deepseek-v4-flash、gpt-4o、glm-4-flash 等）。

深度思考只在官方 DeepSeek 接口时生效；其它接口不会发送该参数（兼容性更好）。各群聊可在「群设置 → API」单独覆盖 Key。

深色风格为黑夜模式，主色调为黑色；卷轴风格为略微泛黄、古朴的书籍质感。均只改变配色与风格，不影响界面布局与图标样式。

开启后，聊天输入框上方的「下轮对话」人物选择条隐藏头像，只显示名字。

群设置 ·

开启后，成员会每过一段时间把聊过的内容提炼进各自的「记忆」，下次对话能记住。每个成员的记忆可在 ✎ 编辑里查看和修改。

防止对话太久后遗忘关键事件：某关键词被提及时，所有成员都会查看它的详情进行回忆，再按剧情需要选择性作出反应。关键词详情不会被「总结」压缩。

所有 AI 成员都会遵守这段世界观，并在言行中体现它。

描述「我」（你）的身份/性格/关系，所有 AI 成员会据此对待你。

导入一部小说 / 剧情文本，AI 会自动分析剧情，生成一批 AI 成员（自动判定主要 / 次要 / 路人角色，并为每人生成人设、记忆与关键词）、世界观（含世界观关键词）和玩家设定，一键应用到本会话。会替换当前全部成员，历史对话记录保留。

未选择文件（支持 txt / md / markdown）

生成的内容会忠于原文，不会编造剧情里没有的人物与设定；剧情流程总结会写入会话「总结」，续写时不会遗忘原剧情走向。生成成功后本会话立即生效，最后记得点「保存」保存其它设置。

本群填了 API Key 才用自己的 API：此时接口地址 / 模型名称（留空则用全局）一起对本群生效；本群 Key 留空则完全用全局设置。

把本群的对话记录、成员人设与记忆、AI 人数、世界观与世界观关键词、成员关键词、玩家设定、群名头像、总结内容等全部设定打包成一份文件，导出下载到本地。出于安全考虑，本群单独设置的 API Key 不会包含在备份里。要载入别人的备份，请在主页点「＋」→「导入记忆」。

清空后本群全部聊天记录将被删除，不可恢复。确认需等待 5 秒。

删除后该群聊将从主页列表消失，全部对话记录一并删除，不可恢复。确认需等待 5 秒。
