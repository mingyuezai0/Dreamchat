梦语

梦语是一款连接各家大模型接口的多 AI 人物群聊软件，纯浏览器本地运行：和最多 8 位 AI角色在「群聊」聊天，或写下「故事」让它们一起演剧情，记录保存在本机。

全局设置

默认官方 DeepSeek 地址，可改成任意 OpenAI 兼容服务的地址（各服务通常以 /v1 结尾）。

填你所选接口服务商发的 API Key（可在其官网注册获取）。

手填模型名，各家格式不同（如 deepseek-v4-flash、gpt-4o、glm-4-flash 等）。

深度思考只在官方 DeepSeek 接口时生效；其它接口不会发送该参数（兼容性更好）。各群聊可在「群设置 → API」单独覆盖 Key。

深色风格为黑夜模式，主色调为黑色；卷轴风格为略微泛黄、古朴的书籍质感。均只改变配色与风格，不影响界面布局与图标样式。

群设置 ·

开启后，成员会每过一段时间把聊过的内容提炼进各自的「记忆」，下次对话能记住。每个成员的记忆可在 ✎ 编辑里查看和修改。

所有 AI 成员都会遵守这段世界观，并在言行中体现它。

描述「我」（你）的身份/性格/关系，所有 AI 成员会据此对待你。

给这个群单独用一个 API Key；留空则使用左下角全局设置里的 Key。

把本群的对话记录、成员人设与记忆、AI 人数、世界观、玩家设定、群名头像、总结内容等全部设定打包成一份文件，导出下载到本地。出于安全考虑，本群单独设置的 API Key 不会包含在备份里。要载入别人的备份，请在主页点「＋」→「导入记忆」。

清空后本群全部聊天记录将被删除，不可恢复。确认需等待 5 秒。

删除后该群聊将从主页列表消失，全部对话记录一并删除，不可恢复。确认需等待 5 秒。
